# Evidence Synthesis at University College Maastricht

Source of the course website [ucm.meta-research.nl](https://ucm.meta-research.nl) for the Evidence Synthesis semester:

* SKI3010 Evidence Synthesis 1: Study Designs in Systematic Reviewing (period 4)
* SKI3011 Evidence Synthesis 2: Statistics in Systematic Reviewing (period 5)
* PRO3017 Evidence Synthesis 3: Systematic Review Research Project (period 6)

The site is built with [Quarto](https://quarto.org). Every push to `main` renders the site and publishes it to GitHub Pages (see `.github/workflows/publish.yml`).

To preview locally:

```bash
quarto preview
```

This repo is supported by Claude Code, commit messages are generated by Copilot.
