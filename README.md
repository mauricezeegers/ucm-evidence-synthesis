# Evidence Synthesis at University College Maastricht

Source of the course website [ucm.meta-research.nl](https://ucm.meta-research.nl) for the Evidence Synthesis semester:

* SKI3010 Evidence Synthesis 1: Study Designs in Systematic Reviewing (period 4)
* SKI3011 Evidence Synthesis 2: Statistics in Systematic Reviewing (period 5)
* PRO3017 Evidence Synthesis 3: Systematic Review Research Project (period 6)

The site is built with [Quarto](https://quarto.org). Every push to `main` renders the site and publishes it to GitHub Pages (see `.github/workflows/publish.yml`).

## Where things are

* `data/ski3010.yml`, `data/ski3011.yml`, `data/pro3017.yml`: the schedules (weeks, sessions, quizzes, assignments, deadlines). `scripts/build.py` turns them into the schedule pages, week pages, `deadlines.qmd` and `calendar.ics`; those generated files are not in git.
* `index.qmd`, `<module>/index.qmd`, `<module>/syllabus.qmd`, `submit.qmd`, `tools.qmd`, `rubrics.qmd`, `ai.qmd`: handwritten pages.
* `ski3011/r-lecture-N.qmd`: the R lectures. Each one is a web page and, via `scripts/qmd_to_r.py`, a downloadable R script in `materials/ski3011/`.
* `materials/<module>/week-N/`: downloads, listed automatically on the week page.
* `_freeze/`: stored R results, so the site builds without R.

Quarto also writes `llms.txt` and a Markdown copy of every page (`*.llms.md`), so the course content is easy to read for AI tools.

To preview locally:

```bash
python3 scripts/build.py && quarto preview
```
